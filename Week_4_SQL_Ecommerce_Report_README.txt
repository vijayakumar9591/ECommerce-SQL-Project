WEEK 4 - SQL E-COMMERCE REPORT

File:
    Week_4_SQL_Ecommerce_Report.sql

Database:
    MySQL 8.x

How to run:
1. Open MySQL Workbench / phpMyAdmin / MySQL command line.
2. Open the .sql file.
3. Run the complete script.
4. The script creates a database named ecommerce_week4.
5. It creates 6 tables, inserts sample e-commerce data, and executes 51 numbered queries.

Covered topics:
- DDL and constraints
- PRIMARY KEY / FOREIGN KEY
- UNIQUE / NOT NULL / CHECK / DEFAULT
- SELECT, WHERE, ORDER BY, LIMIT
- COUNT, SUM, AVG, MIN, MAX
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Customer spending analysis
- Top products and category revenue
- NULL handling with IS NULL and COALESCE
- Subqueries
- CASE expressions
- Date-based reports
- Inventory analysis
- Index creation
